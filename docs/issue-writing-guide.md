# Issue 撰寫規範

> 本文件定義 Taiphoon_QGCS 的 issue 撰寫格式與條件。
> 建立或更新 issue 前，請先閱讀本文件與 `docs/agents/issue-tracker.md`。

## 目的

Issue 的目的是讓開發者快速理解問題、重現步驟、預期行為與目標，避免在 issue 內容中夾帶未經證實的猜測。

## 適用範圍

所有 Taiphoon_QGCS 的 issue，無論存放於 `.scratch/` 或日後的專案儲存庫，發布前均應依本規範撰寫。

## 語言原則

- 內容以繁體中文為主，包含標題。
- 專有名詞若無準確中文翻譯，可保留英文，例如 ARM、FORMATION、DDS、QML、signal、commit、log。

## 標題格式

格式：`模組: issue 內容`

範例：
- `命令: 解鎖與編隊指令無效，無人機無反應且未收到成功回執`
- `機隊: 機群視窗未顯示離線 Agent`
- `文件: 補充 UiBridge 屬性說明`

模組名稱依專案既有模組調整，例如 命令、防呆、編隊、遙測、機隊、地圖、介面、通訊、打包、文件。

## 類型

| 類型 | 使用時機 |
|------|----------|
| Bug | 當程式運行的方式不如預期時 |
| Feature | 需要增加新的功能時 |
| Documentation | 文件需要新增或修改時 |

類型名稱（Bug、Feature、Documentation）不需翻譯，可另加專案標籤。

## 欄位結構

### 標題

一句話講清楚問題或需求，格式為「模組: issue 內容」。

### 類型

標註 Bug、Feature 或 Documentation，可視需要補充標籤。

### 描述

具體描述問題或需求。Bug 只描述實際操作時發現的現象，不做任何猜測。

### 重現步驟

Bug 必填。以編號列出可重複的操作步驟，包含啟動環境、操作位置、等待時間與觀察結果。

### 預期行為與實際行為

Bug 必填。明確對照「應該發生什麼」與「實際發生什麼」。Feature / Documentation 可改寫為需求與預期結果。

### 執行環境

記錄可重現問題所需的環境資訊，例如：

- 主機作業系統
- GCS commit / 版本，以及執行方式（安裝版或開發建置）
- Agent 數量與版本
- 模擬器或實機
- 相關 log

## 撰寫條件

- 只撰寫實際操作時發現的現象，不做任何猜測。
- 不把根因、修正方向或未經驗證的假設寫進 issue 內容。
- 重現步驟必須具體、可重複，並包含觀察結果。
- 預期行為與實際行為必須清楚對照。
- 執行環境資訊應完整，方便開發者重現。
- Feature 與 Documentation 不需重現步驟，但需清楚描述需求、動機與預期結果。

## 撰寫範例

```markdown
# 命令: 解鎖與編隊指令無效，無人機無反應且未收到成功回執

## 類型

- 類型：Bug
- 標籤：命令 / ARM / FORMATION

## 描述

透過 GCS 飛行控制面板發送「解鎖（ARM）」與「環形編隊（FORMATION_CIRCLE）」指令時，指令無法生效：ARM 未讓無人機解鎖，FORMATION_CIRCLE 逾時且未形成編隊。手動發送切換 OFFBOARD 模式、解鎖與起飛命令後，無人機可正常進入飛行狀態。

## 重現步驟

1. 啟動 GCS、四台 Agent 與 PX4 模擬器，確認狀態列連線燈號為已連線，機群視窗顯示四台 Agent 上線。
2. 在控制面板「安全開關」區執行「滑動以解鎖（ARM）」。
3. 等待數秒後確認無人機狀態，實際上未解鎖。
4. 手動發送切換 OFFBOARD 模式、解鎖、起飛命令（非透過 GCS 控制面板），確認無人機可正常起飛。
5. 在「全部機隊」模式下展開「編隊命令」，發送「環形編隊」（FORMATION_CIRCLE）。
6. 觀察提示訊息，顯示「FORMATION_CIRCLE 逾時」，且無人機並未成功形成編隊。

## 預期行為與實際行為

預期行為：
- ARM：無人機完成解鎖，狀態轉為「已解鎖（ARMED）」，GCS 顯示成功回執。
- FORMATION_CIRCLE：指令成功廣播至 `/uav_all_agent/command`，無人機依指令形成環形編隊，GCS 顯示成功回執。

實際行為：
- 在 GCS 控制面板執行 ARM：無人機未解鎖。
- 在 GCS 控制面板發送 FORMATION_CIRCLE：GCS 顯示「FORMATION_CIRCLE 逾時」，無人機未形成編隊。
- 手動發送 OFFBOARD 模式、解鎖、起飛命令後，無人機可正常起飛。

## 執行環境

- 主機作業系統：Windows 11（GCS 安裝版）
- GCS commit：（範例）
- Agent 數量：4 台
- 模擬器：PX4 模擬器
- Agent 介面版本：taiphoon-agent-interface.md v1.1（2026-07-31）
- GCS log / Agent log：待補
```
