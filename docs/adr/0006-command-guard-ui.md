# ADR-0006：關鍵指令二級 UI 防呆

**日期**：2026-07-30
**狀態**：已接受

## 背景

Arm、Takeoff 等關鍵指令需在前端防止誤觸。後端 GuardModule 負責狀態機驗證，前端需提供操作防護。

## 決策

採用 **二級 UI 防呆**，不使用三級。

| 層級 | 機制 | 適用指令 |
|------|------|----------|
| L1：兩步驟確認 | 點擊後彈出確認對話框，顯示當前狀態 | Takeoff、RTL、Land、Disarm |
| L2：長按滑桿 (Slide-to-Confirm) | 拖曳滑桿到底觸發，防止單擊誤觸 | Arm |

## 替代方案

| 方案 | 否決原因 |
|------|----------|
| L3 雙因子確認 | 操作延遲過高，L1+L2 已足夠覆蓋使用場景 |

## 後果

- Arm 元件需實作自訂 Slide-to-Confirm 互動
- L1 確認對話框需顯示 Agent 當前狀態供操作者二次確認
