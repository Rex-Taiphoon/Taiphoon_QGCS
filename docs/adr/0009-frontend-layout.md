# ADR-0009：前端面板佈局

**日期**：2026-07-30
**狀態**：已接受（Qt 原生版沿用版面；地圖實作見 ADR-0016）

## 決策

```
┌──────────────────────────────────────────────────────────┐
│ 狀態列：選中無人機 | Mode: HOVER | Batt: 85% | NED(10,-3,-5) │
├──────────────────────────────────────────────────────────┤
│ [飛行控制]              全幅地圖       [機群管理  台數 −] │
│  可展開控制面板         MapLibre GL    │ 機群數量        ││
│                                      │ 圓角無人機卡片  ││
│                  ➤ 無人機標記         └────────────────┘│
│                                                          │
└──────────────────────────────────────────────────────────┘
```

- 頂部狀態列：固定 60 像素高；選中無人機的即時 telemetry 摘要過長時以水平捲動呈現，
  連線燈號與設定入口保持可見。
- 左側控制面板：以「安全開關／模式控制／移動與 YAW／編隊命令」四頁分頁呈現，保留原有防呆互動
- 中央地圖：MapLibre GL 主畫面，以依航向旋轉的箭頭顯示無人機，箭頭下方標示 Agent 名稱
- 地圖右上方機群懸浮視窗：不佔用固定側欄，支援選中單機或全體；以「機群數量」顯示線上台數，
  每台無人機資訊使用獨立圓角卡片。可最小化為保留標題與台數的標題列，再以展開按鈕打開。
  清單可捲動，窄視窗下移至飛行控制入口下方，並保留底部導覽控制的操作空間。
- 地圖縮放與朝北按鍵位於右下角；移除 MapLibre 字樣及原本右下角的資訊按鈕，
  將 OSM 必要來源標示保留於左下角。
- 頂列品牌圖示為 50 × 50 像素；連線狀態以燈號呈現，保留滑鼠提示與輔助閱讀標籤。
- Debug 終端機：移至「進階設定」內，不再固定顯示於地圖左下角
